# Development Tools

This directory contains development utilities and helper tools for the Gantt Chart application.

## Files

### HTML Testing Tools

- **`clear-and-add-dependencies.html`** - A standalone HTML tool that clears localStorage and adds sample tasks with dependencies. Open in a browser to use.

- **`test-dependencies.html`** - A tool for adding test dependencies to existing tasks in localStorage. Useful for testing dependency visualization.

- **`test-drag-drop.html`** - A placeholder file for drag-and-drop testing utilities.

### Other Utilities

- **`clear-storage.txt`** - Documentation or script for clearing application storage.

## Usage

These tools are designed to help with development and testing. They interact with the browser's localStorage to manipulate test data for the Gantt chart application.

To use any of the HTML tools:
1. Start the main application (`npm run dev`)
2. Open the desired HTML tool in a separate browser tab
3. Use the buttons/interface to manipulate test data
4. Refresh the main application to see the changes

## Note

These tools are for development purposes only and should not be included in production builds.
